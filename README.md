# Hand Gesture Control - Temple Run

An innovative computer vision project that allows users to play the popular mobile game **Temple Run** using real-time hand gestures tracked via webcam.

---

## 🚀 Features
* **Real-Time Tracking:** Uses MediaPipe and OpenCV to accurately detect hand movements and gestures.
* **Gesture Mapping:** Maps specific hand motions to game controls (Left, Right, Jump, Slide).
* **Interactive Gameplay:** Provides a seamless, touch-free gaming experience using PyAutoGUI.

---

## 🛠️ Tech Stack & Libraries
* **Python**
* **OpenCV** (For video capture and image processing)
* **MediaPipe** (For hand landmark tracking)
* **PyAutoGUI** (For automating keyboard inputs to control the game)
